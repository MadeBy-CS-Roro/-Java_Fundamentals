## 📌 About This Repository
This repository serves as my official introduction to software development. It contains my academic coursework, logic-building exercises, and initial projects for **Computer Programming 1 (CSC 111)**, establishing the core programming foundation required for advanced computer science and cybersecurity fields.

This repository documents my progression from basic syntax to logical problem-solving, covering:

*   **Core Logic:** Variables, Data Types, and Operators.
*   **Control Flow:** Conditional statements (If-Else, Switch) and iterative Loops (For, While).
*   **Methods & Arrays:** Modular programming, code reusability, and basic data manipulation.
*   **🔐 Mini-Project (Encryption/Decryption):** A hands-on project applying core logic to manipulate strings and build a basic text encryption/decryption tool[span_4](start_span)[span_4](end_span).
